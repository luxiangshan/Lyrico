# Lyrico Mod for Windows 1.7.0

两种下载（都自带 Java 运行环境，无需另外安装 Java）：

- `LyricoMod-1.7.0-*-windows-x64.msi`：安装版（安装到当前用户，开始菜单和桌面快捷方式）。
- `LyricoMod-1.7.0-*-windows-x64-portable.zip`：便携版，解压后运行 `Lyrico Mod\Lyrico Mod.exe`。

## 本版更新
- **修复（数据丢失）：批量编辑会清空所选歌曲的 ID3 信息和封面。** 原因：勾选但内容为空的字段会被当作「清除」，〈多个值〉字段的输入框本身是空的，所以「全选」后应用会清空标题、艺术家等所有不同值的字段；封面勾选但没选图片 = 移除封面。现在：
  - 只写入你**真正修改过**的字段（输入新值会自动勾选）；单独勾选、「全选」都不会写入或清除任何内容，「全选」只勾选已修改的字段。
  - 〈多个值〉的字段不输入就保留每首歌各自的值；把输入框删空也不算清除。要清除某字段请点该字段右侧的「清空」。
  - 封面只在「选择图片…」或「移除封面」后才会修改，否则保持不变。
  - 应用前的确认框逐项列出将修改/清除的内容，其余字段保持原样。
- **新增「批量匹配」**（多选后的首要操作）：用插件为每首歌自动查询歌曲信息、歌词和封面并写入，匹配算法与安卓版相同（同样的分数阈值，低于阈值跳过）。可选填写字段（标题/艺术家/专辑/专辑艺术家/音轨/碟号/年份/流派/作曲/作词/歌词/封面，可全选）、写入方式「补充（只填空白字段）/ 覆盖」、按文件名匹配、同时处理 1–4 首、本次使用的插件。显示进度和每首结果（来源+分数 / 未匹配原因 / 失败原因）。插件结果里没有的字段永远不会被清空。
- 写入层修复：已有 ID3v2.4 标签的 MP3 不再被转换成 v2.3（之前会改写日期等帧）；只有 ID3v1 的 MP3 新建 v2 标签时带上 v1 的信息；ID3v1 与修改的字段同步（仅限 ISO-8859-1 可表示的值）；修改「注释」不再删除 iTunNORM 等其他注释帧，保留原语言；更换封面只替换正面封面，保留背面等其他图片；远程歌曲下载不完整时拒绝写入和上传。

## 功能
- 添加本地文件夹，扫描 MP3 / FLAC / M4A / OGG / Opus / WAV / AIFF / WMA / DSF / APE / WavPack，歌曲列表支持搜索、排序、封面缩略图。
- 编辑标题、艺术家、专辑、专辑艺术家、音轨/碟号、年份、流派、作曲、作词、注释、封面（更换/移除/导出）和歌词。
- 歌词可「写入标签」「保存为 LRC」或「两者都要」（设置中可设默认值）：
  MP3 写入 ID3v2 USLT（原样保留 LRC 时间标签，语言 chi/XXX 可选），FLAC/OGG/Opus 写入 LYRICS，M4A 写入 ©lyr，WAV/AIFF 写入 ID3 块，APE/WV 写入 APEv2 Lyrics。
  LRC 默认与歌曲同名、同目录，UTF-8（可选 BOM 和 CRLF）。
- 远程位置：WebDAV、OpenList/Alist、SMB、115（扫码登录）——下载编辑后上传覆盖，LRC 上传到歌曲旁边。
- 插件：与安卓版通用的 JS 插件（GraalJS 运行），支持本地导入 ZIP、订阅 catalog.json 在线安装/更新、插件配置与排序；编辑页可搜索歌词 / 封面 / 歌曲信息，多选可批量匹配歌曲信息、歌词和封面；可单独启用插件、按次选择插件。

数据目录：`%APPDATA%\LyricoMod`。
