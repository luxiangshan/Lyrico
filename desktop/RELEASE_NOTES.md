# Lyrico Mod for Windows 1.7.0

两种下载（都自带 Java 运行环境，无需另外安装 Java）：

- `LyricoMod-1.7.0-*-windows-x64.msi`：安装版（安装到当前用户，开始菜单和桌面快捷方式）。
- `LyricoMod-1.7.0-*-windows-x64-portable.zip`：便携版，解压后运行 `Lyrico Mod\Lyrico Mod.exe`。

## 本版更新
- 批量编辑：每个字段（标题、艺术家、专辑、专辑艺术家、音轨号/总数、碟号/总数、年份、流派、作曲、作词、注释、歌词、封面）都有「应用」勾选框，右上角「全选 / 全不选」。只写入勾选的字段；勾选但留空 = 清除该字段（应用前会列出将被清除的字段并要求确认）。所选歌曲值不同时显示〈多个值〉。
- 批量封面：选择 jpg / png / webp 图片应用到所有所选歌曲，或「移除封面」。MP3、FLAC、M4A、OGG、Opus、WAV、AIFF、APE、WavPack 都会写入；远程歌曲下载→写入→上传。修复：之前 FLAC / OGG 写入 WebP 封面会失败。
- 导出 LRC（编辑页和批量）改为对话框：可「选择导出目录」（可「清除」回到默认的歌曲所在文件夹）；导出到目录时同名文件可「覆盖 / 跳过 / 重名时加序号」（如「晴天 (2).lrc」）；可勾选「记住导出目录」。远程歌曲导出到本地目录时直接写本地。
- 插件：每个插件有「启用」开关（提供多种功能的插件还可单独开关 歌曲信息 / 歌词 / 封面），停用的插件不会被搜索和批量匹配调用；搜索窗口和批量匹配对话框可勾选本次使用哪些插件（默认全部已启用的）。设置会保存。
- 官方插件订阅链接在 GitHub「最新版」缺少 catalog.json 时，自动改用带有 catalog.json 的最新发行版（含预发布）。

## 功能
- 添加本地文件夹，扫描 MP3 / FLAC / M4A / OGG / Opus / WAV / AIFF / WMA / DSF / APE / WavPack，歌曲列表支持搜索、排序、封面缩略图。
- 编辑标题、艺术家、专辑、专辑艺术家、音轨/碟号、年份、流派、作曲、作词、注释、封面（更换/移除/导出）和歌词。
- 歌词可「写入标签」「保存为 LRC」或「两者都要」（设置中可设默认值）：
  MP3 写入 ID3v2 USLT（原样保留 LRC 时间标签，语言 chi/XXX 可选），FLAC/OGG/Opus 写入 LYRICS，M4A 写入 ©lyr，WAV/AIFF 写入 ID3 块，APE/WV 写入 APEv2 Lyrics。
  LRC 默认与歌曲同名、同目录，UTF-8（可选 BOM 和 CRLF）。
- 远程位置：WebDAV、OpenList/Alist、SMB、115（扫码登录）——下载编辑后上传覆盖，LRC 上传到歌曲旁边。
- 插件：与安卓版通用的 JS 插件（GraalJS 运行），支持本地导入 ZIP、订阅 catalog.json 在线安装/更新、插件配置与排序；编辑页可搜索歌词 / 封面 / 歌曲信息，多选可批量匹配歌词。

数据目录：`%APPDATA%\LyricoMod`。
